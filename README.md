# 设备防搬动与异常事件记录终端

基于 i.MX6ULL ALPHA eMMC 开发板、7寸 RGB 触摸屏和板载 ICM20608 的 ELIN4120 嵌入式系统课程项目。程序在开发板本地采集六轴数据，完成静止校准、持续异常判断、锁存报警和事件追溯，不依赖摄像头。

![实机桌面](docs/images/desktop.png)

## 功能

- 静止参考姿态、低通滤波、持续时间和回差，区分短碰与持续倾斜或动态异常。
- 校准、倒计时布防、锁存报警、消音、撤防、数据断流与恢复状态机。
- Qt Quick HUD、SQLite 事件和前后趋势、原子配置保存、CSV 导出。
- 16图标单页桌面、右侧返回/主页/任务导航、真实后台驻留。回主页后监测继续；任务页结束才释放进程。
- 针对原厂开机与SSH环境不同导致的旧缓存问题，固定独立缓存目录；已有整板软件重启证据。

## 目录

`src/guard/`为检测与存储；`src/ui/`为Qt界面；`src/fast_launcher.c`负责采集与图形进程协调。`tests/`为确定性逻辑和存储测试。`tools/`为构建、检查与备份工具。`system_desktop/theme_v1/`为主题、三键导航、原生任务服务与恢复脚本。`evidence/`保存筛选后的验证记录。

## 先复现逻辑测试

在Linux或WSL中运行：

```sh
python3 tests/test_engine.py
```

14项测试覆盖校准、非法参数、短碰、持续倾斜/旋转、故障恢复和SQLite持久化。系统需要SQLite动态库。Windows上建议使用WSL执行；这不是依赖真实传感器的硬件测试。

## 开发板构建与部署

目标环境为ARMv7 Linux、Qt 5.12.9和Python 3.5；传感器设备为 `/dev/icm20608`，帧缓冲为1024×600 RGB565，触摸使用板端实际输入节点。

1. 在已安装ARM交叉GCC的WSL运行 `sh tools/build_launcher.sh`，生成自己的原生启动器。
2. 完整后台与三键功能需要主题任务服务：运行 `sh system_desktop/theme_v1/build_native.sh` 构建。不要把“最近使用”与进程驻留混为一谈。
3. 主题的原厂QRC适配需要从自己的合法开发板镜像取得原始应用。按照 [主题说明](system_desktop/theme_v1/说明.md) 准备 `original_apps/` 与 `original_systemui`，执行 `python3 prepare_apps.py` 和 `python3 pack_theme.py` 等构建步骤。准备图像原图时可选用本仓库已提供的运行尺寸资产；高分辨率生成原图不属于运行必需文件。
4. 安装脚本针对本项目已核对的原厂版本和此前单页桌面，有SHA256前置检查；版本不符会停止，不能将此包当成任意型号开发板的刷机镜像。系统没有修改U-Boot或BOOT拨码。
5. `python3 tools/pack.py` 生成程序部署包。上传到开发板独立的 `/opt/device_guard`，不要覆盖真实数据目录。所用SSH地址和可信主机公钥由每台设备在本机配置，不随公开仓库发布。
6. 板端用 `python3 /opt/device_guard/launcher.py` 启动。已有原生Qt宿主时可加快界面启动；本仓库不分发厂商派生宿主二进制，没有该宿主时使用qmlscene。`--replay` 是明确标记的模拟输入，不能当作真实硬件结果。

基础采集服务也可单独启动 `python3 src/run.py --data ./data --replay --no-indicators`，仅监听127.0.0.1:18765。完整HUD后台导航还需要本机127.0.0.1:18767的任务服务。二者没有远程用户认证，面向本机课程实验环境。

## 已验证与边界

实机记录覆盖真实倾斜29.29°、触摸与声音接口、配置/事件保留、文件和编辑页驻留、后台持续采集、整板软件重启后的侧栏与单页。回放另覆盖短碰、持续异常和断流恢复。启动性能JSON注明版本、同次开机条件和测量方法，不是所有应用的帧率或冷启动保证。

没有长期误报率、复杂搬动全覆盖、拔电一致性或多设备统计结论。六轴姿态和动态变化不等于绝对位置；保持姿态的缓慢平移可能漏检。软件重启证据不等于反复断电试验。
